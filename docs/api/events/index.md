# Events

## Получение списка мероприятий

```http
GET /api/v0/events/
```

### Фильтрация

| Параметр | Значения          | По умолчанию     |
|----------|-------------------|------------------|
| `period` | `past`, `future`  | все мероприятия  |

### Сортировка

| Параметр | Значения                  | По умолчанию                                    |
|----------|---------------------------|-------------------------------------------------|
| `sort`   | `started_at`, `ended_at`  | `started_at`                                    |
| `order`  | `asc`, `desc`             | `desc` для `period=past`, иначе `asc`           |

Если у мероприятия не указана дата конца, при сортировке по `ended_at` используется дата начала.

## Даты

`start_datetime` и `end_datetime` передаются строкой в формате [ISO 8601](https://iso8601.com/)

# Events

## Получение списка запланированных мероприятий

```http
GET /api/v0/events/
```

## Получение списка прошедших мероприятий

```http
GET /api/v0/events/past/
```

### Сортировка

| Параметр | Значения                  | По умолчанию                                                           |
|----------|---------------------------|------------------------------------------------------------------------|
| `sort`   | `started_at`, `ended_at`  | `started_at`                                                           |
| `order`  | `asc`, `desc`             | `asc` для запланированных, `desc` для прошедших (от ближнего к дальнему) |

Если у мероприятия не указана дата конца, при сортировке по `ended_at` используется дата начала.

## Проверка дат

При создании и обновлении мероприятия (`POST` и `PUT`) даты `start_datetime` и `end_datetime` проверяются. Если дату не удалось распознать, возвращается `400`, в `loc` указано поле с ошибкой:

```json
{
  "detail": [
    {
      "msg": "Не удалось распознать дату: когда-нибудь",
      "loc": ["start_datetime"],
      "type": "value_error"
    }
  ]
}
```

В админке такая дата подсвечивается ошибкой у поля.

# stud-iu-back

Бэкенд сайта «Стундеческого совета факультета ИУ»

> Для запуска документации потребуется установленный инструмент **[uv](https://docs.astral.sh/uv/)**.

Запустите локальный сервер документации из корня проекта:

```shell
uv run mkdocs serve
```

Документация будет доступна по следующему адресу: <http://127.0.0.1:8000>
